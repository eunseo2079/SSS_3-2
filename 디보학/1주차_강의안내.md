# 1주차: 디지털보안학
### AI sys은 *정보시스템* 위에서 동작한다
ai 서비스는 네트워크, 서버, 데이터, 애플리케이션 위에 얹힌 하나의 층 

<img width="503" height="254" alt="image" src="https://github.com/user-attachments/assets/bc2d9816-7bca-4c09-9dfc-505fdc6e34f0" />

- **ai 모델, 서비스**-> **ai 고유의 위협** 받음
- **애플리케이션, api / 데이터, 저장소 / 서버, 엔드포인트 / 네트워크, 계정** -> **실제 침투가 일어나는** 곳임
  - ai 고유의 위협? 프롬프트 인젝션, 데이터 오염, 모델 탈취 등
  - 실제 침투? 계정 탈취, 인증우회, 패치되지 않은 취약점 등
  - (ai를 노린 공격 또한 아래 네 개의 취약점 통해 들어옴)
 
### AI를 노린 공격은 어디로 들어오는가?
- **적대적 공격**: 미세한 입력 조작 -> 모델의 판단 뒤집음
- 성립조건: 입력경로 (api. 업로드 기능)에 접근 가능해야
- **데이터 오염**: 학습, 튜닝 데이터에 악의적 표본 섞음 -> 모델 왜곡
- 성립조건: 데이터 수집경로, 저장소에 쓰기 권한 확보해야
- **모델, 프롬프트 탈취**: 가중치/ 시스템 지시문 빼내는 공격
- 성립조건: 모델 파일이 있는 서버, 저장소에 접근 or API 남용해야

--> **공통점**: 공격 이름은 AI지만, 성립 조건은 계정, 권한, 서버, 네트워크의 취약점

### 침해는 *정보시스템 취약점*을 따라 진행
가장 약한 문 하나가 열리면, 공격자는 안에서 옆으로 이동해 데이터에 도달한다

<img width="455" height="203" alt="image" src="https://github.com/user-attachments/assets/bb298240-10cc-4d4f-af3a-1089bc26fe3a" />

- **1구간** (최초 침투)
  - 1단계: 계정확보 
  - 2단계: 원격접속 침입
- **2구간** (내부 확산)
  - 3단계: 내부 PC 장악
  - 4단계: 권한 상승, 횡적 이동
- **3구간** (데이터 유출)
  - 5단계: 데이터 수집
  - 6단계: 외부 반출
  
--> 언론에 보도 되는 것 -> 1-2구간 **BUT** 실제 피해는 3-6단계

### 침해사고가 나면 무엇을 잃는가
- **데이터 유출**: 고객 data, 지적 재산, 금융 정보 손실 (시스템은 복구 가능해도 이건x)
- **서비스 거부** 디도스나 랜섬웨어 -> 서비스 자체가 중지
- **재정적 손실**: 복구, 법률 비용, 매출 손실, 과징금
- **평판, 고객 손실**: 기술적 복구 끝나도 이어짐

--> AI 시스템이라면, 오염된 모델은 사고 인지 전까지 계속 잘못된 판단을 내보내는 문제도 있음


### 정보시스템 기본 골격
| 구분 | 역할 | 예시 |
|---|---|---|
| 네트워크 | 데이터가 오가는 통로 | 방화벽, VPN, 프로토콜 |
| 서버·엔드포인트 | 프로그램이 실제로 실행되는 곳 | OS, 컨테이너, 클라우드 |
| 애플리케이션·API| 사용자의 요청을 받아 처리하는 논리 | 웹서비스, 인증 로직 |
| 데이터·저장소 | 보호해야 할 최종 목표물 | DB, 파일 서버, 벡터 저장소 |
| 계정·권한 | 모든 계층에 걸쳐 누가 무엇을 할 수 있는지 결정 | |


### 취약점은 어디서 생기는가
1. **설계결함 [인증없이 접근 가능한 내부 API, 평문으로 오가는 통신** 
- 애초에 안전하게 설계 X
2. **구현결함[입력값 검증 누락, 잘못된 권한 확인, 인젝션]**
- 코드 작성시 결함
3. **설정오류[기본 비밀번호, 공개된 관리 포트, 과도하게 넓은 접근 권한]**
- 기능은 정상, 설정이 결함
4. **운영실패[패치 미적용, 자산목록부재, 로그 남기지만 보지않음]**
- 알려진 취약점 알면서 못고침
5. **사람**
- 피싱에 속거나 실수로 권한 잘못부여


### 사이버보안이란?
- **사이버보안**
  - 정보 통신 기술의 보안과 관련된 모든 것
  - 인터넷으로 연결된 컴터,서버,모바일 디바이스, 네트워크 -> 허가되지 않은 접근, 데이터 도난, 공격 등에서 보호
- **사이버공격**
  - 타인의 컴퓨터 네트워크에 대한 악의적 공격
  - 공격자가 노리는 것: 데이터 훔쳐보기, 손상시키기, 조작하기

 ### 위협의 분류
 - **기술적위협** by 사이버공격
   - 악의적 사용자의 공격에 의한 위협
- **인적위협** by 사람
  - 의도적 위협 / 우발적 위협
  - 내부 통제, 내부 이상 징후 파악해야함
- **물리적위협** by 정보 자산 파괴 (지진,화재 등의 환경적 위협도 포함)
